# Python - Classes and Objects

This project introduces the basics of Object-Oriented Programming (OOP) in Python:
- Defining classes and creating instances
- Private attributes and name mangling (`__attr`)
- `__init__` and instance attribute initialization
- Simple validation in constructors
- Why encapsulation (keeping attributes private) matters

## Files
- `0-square.py` — Empty `Square` class
- `1-square.py` — `Square` with private attribute `__size` (no validation)
- `2-square.py` — `Square` with size validation in `__init__(size=0)`

More tasks will extend functionality (area, getters/setters, properties, printing, comparisons).

## Requirements
- Python 3
- Files start with `#!/usr/bin/python3`
- PEP8/pycodestyle compliant
