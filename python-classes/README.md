# Python - Classes and Objects

This project is part of the Holberton School Higher Level Programming curriculum. It focuses on understanding and implementing classes and objects in Python.

## Learning Objectives

By the end of this project, you should be able to:
- Understand what a class is and how to use it
- Understand what an object is and how to use it
- Understand the difference between a class and an object
- Understand what `self` is and how to use it
- What is a method and how to use it
- What is an `__init__` method and how to use it
- Understand data attributes and instance attributes
- Understand class attributes and instance attributes
- Understand how to create, instantiate, and use classes
- Understand what the `__dict__` of a class and of an instance contains and how to use it
- Understand what is the difference between a class attribute and an instance attribute
- How to use properties, getters, and setters in Python
- Understand the `@property` decorator
- Understand how to dynamically create arbitrary new attributes for existing instances
- How to bind attributes to object and classes
- Understand what is and how to use the `__str__` and `__repr__` methods
- How to use the `dir()` built-in function

## Requirements

- All files should end with a new line
- All files must have the first line as `#!/usr/bin/python3`
- A `README.md` file, at the root of the folder of the project, is mandatory
- Your code should use the PEP 8 style (version 1.7 or more)
- All your files must be executable
- The length of your files will be tested using `wc`
- You are not allowed to import any module
