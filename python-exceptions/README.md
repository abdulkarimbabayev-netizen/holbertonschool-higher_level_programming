# Python - Exceptions

This project covers how to use exceptions in Python and how to properly handle errors using:
- try / except
- try / except / finally
- safe operations on lists and dictionaries
- raising exceptions
- writing functions that avoid crashing when invalid input is provided

## Learning Objectives
- What’s the difference between errors and exceptions
- What are exceptions and how to use them
- When to use exceptions
- How to correctly handle exceptions
- How to raise built-in exceptions
- How to create clean code that fails safely

Each task explores exception handling using real‑world list and integer operations.
