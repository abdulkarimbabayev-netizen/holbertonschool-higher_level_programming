# Python - More Data Structures: Set, Dictionary

This project continues the practice of Python data structures with a focus on:
- Using lists, sets, and dictionaries
- Working with nested lists (matrices)
- Using list comprehensions
- Using loops, map(), filter(), and lambda
- Returning new lists instead of modifying originals
- Understanding how Python handles mutable vs immutable types

## Tasks included:
0. Compute the square value of all integers in a matrix  
1. Replace all occurrences of an element by another in a new list  
2. Add all unique integers in a list  
3. Return a set of common elements in two sets  
4. Return a set of elements present in only one set  
5. Number of keys in a dictionary  
6. Print a dictionary by ordered keys  
7. Replace or add key/value in a dictionary  
8. Delete a key in a dictionary  
9. Multiply all values of a dictionary by 2  
10. Return a new dictionary with all values multiplied by 2  
11. Convert Roman numeral to integer
